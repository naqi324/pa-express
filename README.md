# Prior Auth Express

A prior authorization app. This repository is an early scaffold.

## Stack

- [Vite](https://vite.dev) with plain TypeScript
- [Oxlint](https://oxc.rs/docs/guide/usage/linter) for linting
- pnpm for packages

## Getting started

```bash
pnpm install
pnpm dev
```

## Scripts

| Command          | Purpose                             |
| ---------------- | ----------------------------------- |
| `pnpm dev`       | Start the dev server                |
| `pnpm build`     | Typecheck, then build to `dist/`    |
| `pnpm preview`   | Serve the production build          |
| `pnpm lint`      | Run Oxlint                          |
| `pnpm typecheck` | Run the TypeScript compiler checks  |
| `pnpm check`     | Run lint and typecheck              |
